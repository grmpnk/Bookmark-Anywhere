<h1 align="center">
  <a href="https://raw.githubusercontent.com/grmpnk/Bookmark-Anywhere/refs/heads/main/icon.svg">
    Bookmark Anywhere
  </a>
</h1>

<p align="center">
  このuserscriptは、Bookmark機能を全てのサイトで使えるscriptです。（サイトごとにbookmarkを保存）
</p>
<p align="center">
  Tampermonkeyのポップアップメニューから保存/削除/開く/ ことができます
</p>

<p align="center">
  <img src="https://raw.githubusercontent.com/grmpnk/Bookmark-Anywhere/refs/heads/main/screenshot.png" alt="Screenshot">
</p>

<br>

<h2>インストール</h2>

<ol>
  <li>
    <strong>Tampermonkey をインストールする</strong>
    <ul>
      <li>
        Chrome:
        <a href="https://chromewebstore.google.com/detail/tampermonkey-%E3%83%99%E3%83%BC%E3%82%BF%E7%89%88/gcalenpjmijncebpfijmoaglllgpjagf">
          Tampermonkey
        </a>
      </li>
      <li>
        Firefox:
        <a href="https://addons.mozilla.org/ja/firefox/addon/tampermonkey/">
          Tampermonkey
        </a>
      </li>
    </ul>
  </li>

  <li>
    <strong>ユーザースクリプトを許可する</strong><br>
    拡張機能の管理で「ユーザースクリプトを許可」してください。詳しくは公式
    <a href="https://www.tampermonkey.net/faq.php?locale=en&q=Q209">
      FAQ
    </a>
  </li>

  <li>
    <strong>スクリプトをインストール</strong><br>
    <a href="https://github.com/grmpnk/Web-Hook-Inspector/raw/refs/heads/main/userscript.user.js">
      ここ
    </a> から インストールできます。
  </li>
</ol>
