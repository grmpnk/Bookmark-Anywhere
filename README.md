<h1 align="center">
  <a href="https://raw.githubusercontent.com/grmpnk/Bookmark-Anywhere/refs/heads/main/icon.svg">
    Bookmark Anywhere
  </a>
</h1>

<p align="center">
  This userscript adds bookmarking functionality to any website. Bookmarks are stored separately for each site.
</p>

<p align="center">
  You can save, delete, and open bookmarks directly from the Tampermonkey popup menu.
</p>

<p align="center">
  <img src="https://raw.githubusercontent.com/grmpnk/Bookmark-Anywhere/refs/heads/main/screenshot.png" alt="Screenshot">
</p>
